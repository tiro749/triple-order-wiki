HOW TO PLAY

最初の3手を、組み立てよう。

「1手」は双方が1回ずつ行動する単位。「3手」はまとめて予約する一区切りです。

01

編成する

4体から3体、各4技、初期前衛を決定。

02

3手を予約

技または交代を選び、3オーダーを確定。

03

結果を確認

1手ずつ処理。3手終了後、次の予約へ。

予約の例

フレイムが前衛で、メイデンに中攻撃を装備している場合。

ORDER 01フレイムの小攻撃
ORDER 02メイデンに交代
ORDER 03メイデンの中攻撃

交代後の前衛が使う技まで予約できます。双方が確定した予約は、原則として途中変更できません。

1手の処理順

  1. 通常の交代

    技より先に交代。相手の技は交代先が受けます。双方交代なら交代前の素早さ順です。

  2. 技の優先度 → 素早さ

    先制攻撃（3）→ 防御（2）→ その他（1）。同じ優先度なら素早さが高い側から、同速ならランダムです。雷走は「その他」の技として攻撃後に交代します。

  3. 毒ダメージ

    毒状態の前衛に5ダメージ。双方が毒なら現在の素早さ順、同速はランダムで処理します。

  4. CTを1減らす

    前衛と控えの全員が対象。ただし、その手で使って設定されたCTはまだ減りません。

交代で変わること

  • 通常交代は1手を消費する。
  • 控えに戻った側がHPを10回復する。
  • 集中と蓄熱は解除。毒は残る。
  • 回復で最大HP100を超えることはない。

戦闘不能になったら

倒された側の、その手の未実行の行動はキャンセル。次の前衛を選び、残りの予約枠をすべて組み直します。

倒した側は残り予約を変更できません。最後の1体が倒されると決着します。

COOLDOWN

CT1は「次の1手」使えない。

CTは技ごとに管理されます。CT1の中攻撃なら「中攻撃 → 小攻撃 → 中攻撃」が可能。CT2の防御は「防御 → 小攻撃 → 小攻撃 → 防御」で再使用できます。

ORDER 01中攻撃 / CT1を設定
ORDER 02別の行動 / 終了時CT0
ORDER 03中攻撃を再使用できる

3手の区切りでCTがリセットされるわけではありません。控えにいる間も進み、予約時点でも前の予約によるCTが反映されます。

勝敗が決まるタイミング

攻撃で最後の生存キャラクターを倒すと、その技の直後に勝敗が確定します。その後の毒で自分が倒れても、勝敗は覆りません。

毒で双方の最後の1体が倒れる場合、先に毒で倒れた側の敗北が確定します。双方への毒処理自体は行われます。

戦闘画面の「降参」からも終了できます。確認画面で「降参する」を選ぶと敗北です。
